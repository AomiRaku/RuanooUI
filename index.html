RuanooUI 组件示例

全部组件由 CSS 变量驱动，浅色与深色两套主题。左侧栏可切换主题， 下方的交互事件会实时记录到侧栏底部。

按钮

圆角 6px、高 32px。三种语义变体共用 .ruanoo-btn 基类； 纯文字操作使用 .ruanoo-icon-btn-text。键盘聚焦有独立焦点环， 禁用态降低不透明度。

<button class="ruanoo-btn ruanoo-btn-primary">保存</button> <button class="ruanoo-btn ruanoo-btn-secondary">取消</button> <button class="ruanoo-btn ruanoo-btn-danger">删除</button> <button class="ruanoo-btn ruanoo-btn-primary" disabled>保存</button> <button class="ruanoo-icon-btn-text"><svg/><span>编辑页面布局</span></button>

输入框

高 36px，描边 3px，聚焦时只换描边颜色、粗细不变。 .ruanoo-input-container 是外壳，负责圆角裁切与校验态； 加 .ruanoo-error 走危险色，配合 .ruanoo-error-tip.ruanoo-active 显示提示。

<div class="ruanoo-input-container"> <input class="ruanoo-input" placeholder="https://example.com"> </div> <div class="ruanoo-input-container ruanoo-error"> <input class="ruanoo-input" value="not-a-url"> </div> <div class="ruanoo-error-tip ruanoo-active"><svg/><span>请输入有效 URL</span></div>

开关

由 .ruanoo-switch::before（左半胶囊）、.ruanoo-slider::before（手柄）、 .ruanoo-switch::after（右半胶囊）三块组成。位置与宽度统一由可过渡变量 --ru-p 推导，因此滑动全程手柄与两侧胶囊的间隙恒为 2px。 纯 CSS 实现，依赖 @property 与 :has()。

<div class="ruanoo-switch-container"> <span class="ruanoo-setting-status-text">关闭</span> <label class="ruanoo-switch"> <input type="checkbox"> <span class="ruanoo-slider"></span> </label> </div>
关闭
打开

手柄关闭态是空心圆环，打开态收成圆头竖线；两侧胶囊的宽度互补伸缩， 末段再渐隐，所以收缩过程不会出现被压扁的弧度。

下拉选择

触发器与浮层都由本库渲染，浮层是 position: fixed，因此不会被父容器的 overflow 裁掉；空间不足时自动向上展开，并收敛到视口内。 支持方向键、Home/End、Enter、Esc， 点击组件之外或按 Tab 都会收起。 选中后派发 ruanoo:select-change。

分段控件

两种外观共用同一套滑块机制：.ruanoo-theme-switch（图标 + 文字，三项等分）与 .ruanoo-layout-presets（缩略图卡片）。滑块由容器上的 .ruanoo-idx-1 / .ruanoo-idx-2 控制位移，首项无需额外类。 分别派发 ruanoo:segment-change 与 ruanoo:preset-change。

<div class="ruanoo-theme-switch" data-ru-segment role="radiogroup"> <button class="ruanoo-theme-option ruanoo-active" role="radio" aria-checked="true"> <svg/> <span class="ruanoo-theme-option-label"> <span class="ruanoo-theme-option-label-inner">系统</span> </span> </button> … </div> <div class="ruanoo-layout-presets" data-ru-presets> <div class="ruanoo-preset-card ruanoo-active" data-ru-layout-val="inspirational" role="radio" tabindex="0" aria-checked="true"> <div class="ruanoo-preset-thumb">…</div> <span class="ruanoo-preset-card-label">展望</span> </div> </div> <!-- 当前配置与任何预设都不匹配时，隐藏滑块 --> <div class="ruanoo-layout-presets ruanoo-no-thumb">…</div>

卡片

.ruanoo-settings-card 不带描边，靠底色与页面区分； .ruanoo-settings-card-header 用于左右分栏的标题行， .ruanoo-settings-content 是卡片的纵向堆叠容器。

浮动层

.ruanoo-quicklink-menu 是右键菜单，.ruanoo-icon-preset-panel 是图标宫格面板。 两者与下拉浮层共用同一套分层方式：透明描边占位 + --ru-dropdown-shadow， 不使用实线边框。层级由 --ru-z-* 变量统一控制。

<div class="ruanoo-quicklink-menu ruanoo-active" role="menu"> <button class="ruanoo-quicklink-menu-item" role="menuitem"> <svg/><span>在新标签页打开</span> </button> </div> <div class="ruanoo-icon-preset-panel ruanoo-active"> <div class="ruanoo-icon-preset-group"> <button class="ruanoo-icon-preset-item ruanoo-selected"><svg/></button> </div> </div>

列表选择项

纵向单列选择，选中态由 aria-selected="true" 驱动而非类名， 左侧指示条是 ::before。支持上下方向键与 Home/End，选中派发 ruanoo:manage-select， detail.action 取自 data-ru-action。

<div class="ruanoo-manage-list" data-ru-manage role="listbox"> <div class="ruanoo-manage-option" role="option" tabindex="0" aria-selected="true" data-ru-action="export"> <svg/><span class="ruanoo-manage-option-label">导出配置</span> </div> </div>

弹窗

外层 .ruanoo-modal-overlay 负责遮罩与显隐，内层 .ruanoo-modal-dialog 承载内容。脚本会自动补上 role="dialog"、aria-modal 与标题关联， 打开时把焦点移入、关闭时归还给触发按钮，并把 Tab 焦点锁在对话框内。 示例里的保存按钮带 URL 校验，校验通过才关闭。

<button class="ruanoo-btn ruanoo-btn-secondary" data-ru-open-modal="my-modal">打开</button> <div class="ruanoo-modal-overlay" id="my-modal"> <div class="ruanoo-modal-dialog"> <div class="ruanoo-modal-header">标题</div> <div class="ruanoo-form-row"> <div class="ruanoo-form-group">…</div> <div class="ruanoo-form-group ruanoo-form-group-narrow">…</div> </div> <div class="ruanoo-modal-footer"> <div class="ruanoo-modal-footer-right"> <button class="ruanoo-btn ruanoo-btn-secondary" data-ru-close-modal>取消</button> <button class="ruanoo-btn ruanoo-btn-primary">保存</button> </div> </div> </div> </div>
